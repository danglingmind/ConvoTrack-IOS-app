# Pre-delivery checklist (Read each PNG)

- [ ] **Thumbnail test**: at ~300 px wide the headline reads and the proof is visible.
- [ ] One idea, headline ≤ 6 words, no filler words.
- [ ] Text ≈ under 20% of the image area (Meta de-prioritises text-heavy images).
- [ ] Screenshot is untouched real UI, current build, demo riders, 9:41 status bar.
- [ ] Chip/overlay covers only empty map, not the featured UI (rider pins, banners, labels).
- [ ] Only the named rider's marker ring is orange (check a 3× crop): route, name, distance label and other riders unchanged; the dotted leader ends just outside that marker.
- [ ] Hero phone: elevated (cast shadow visible on the map beside it), cropped by the bottom edge.
- [ ] Satellite: the road reads in the visible map area; headline zone dark enough; credit on map, not on the screen.
- [ ] Story: nothing important in top ~250 px or bottom ~380 px.
- [ ] Feed 4:5 is the hero size, square and story not cropped awkwardly.
- [ ] Contrast: white/lime on near-black only; no lime text on photos.
- [ ] Claims pass `brand.md` → Claims; "free"/price wording confirmed.
- [ ] `qa.sh` clean: exact size, no alpha, < 30 MB.

Meta specs: feed 1080×1350 (4:5) preferred, 1080×1080 (1:1), Stories/Reels 1080×1920 (9:16);
PNG/JPG ≤ 30 MB. Primary text: first ~125 characters show before "See more", so put the hook there.
Headline ≈ 40 characters max. Add each size as its own ad creative or use placement asset
customisation; keep one concept per ad set when testing.
